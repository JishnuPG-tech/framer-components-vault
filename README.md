## ⚡ Instant Installation via CLI

You can install any component directly into your React or Next.js project using `npx framer-craft` (like `shadcn/ui`):

```bash
# 1. Initialize your project with Framer Motion shims and AI craft rules
npx framer-craft init

# 2. Add an artisanal accordion
npx framer-craft add fold-rows

# 3. Add an award-winning hero showcase
npx framer-craft add diagonal-slideshow

# 4. Search 900+ components from the terminal
npx framer-craft search "liquid button"
```

## 🎨 Why This Vault Exists: The "Anti-AI-Slop" Manifesto

Most AI coding assistants produce **"AI Slop"**—predictable 3-column feature cards, flat `transition: 0.3s ease` linear timing, and generic purple gradients.

This vault serves as the **living Source of Truth** for high-craft digital experiences:
- **Calibrated Spring Physics**: Real mass, stiffness, and damping curves instead of flat robotic CSS transitions.
- **Typographic Tension**: Negative tracking (`letter-spacing: -0.045em`), high-contrast hierarchy, and monospace micro-labels.
- **Artisanal Surfaces**: Multi-layered frosted glass, inner highlight borders (`inset 0 1px 1px rgba(255,255,255,0.15)`), and dynamic directional glow shaders.

## 🤖 AI Agent Integration

### Using with Antigravity
The vault includes a native Antigravity skill in `skills/framer-craft-vault/`. Whenever you instruct Antigravity to build or polish a UI, it automatically searches the vault for matching human-designed primitives.

### Using with Cursor, Claude, or ChatGPT
Copy `SYSTEM_PROMPT.md` into your Custom GPT, Claude Project Instructions, or drop `.cursorrules` into your project root. The AI will strictly follow the Anti-AI-Slop laws and pull real spring curves.

## 🌐 Live Intelligence API

The vault is backed by a live REST API:

| Endpoint | Description |
| :--- | :--- |
| `GET /api/dna` | Codified motion presets (`snappy`, `fluid`, `editorial`) and typography rules |
| `GET /api/categories` | Complete category breakdown and item counts |
| `GET /api/catalog` | Token-efficient component index |
| `GET /api/search?q={query}` | Search by keyword, category, or trait |
| `GET /api/components/{slug}/inspect` | Deep inspection of component props, dependencies, and springs |
| `GET /api/components/{slug}/code?raw=true` | Download raw standalone TypeScript code |
| `GET /api/recommend?use_case={goal}` | Curated recommendations (`hero`, `landing`, `pricing`, `cards`) |
